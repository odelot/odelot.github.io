Privacy Policy - NES RA Adapter

Last updated: 2025-05-14

This Android application is designed to function as a WebView interface for the NES achievement adapter, accessing a locally hosted page on the user’s network.

1. Data Collection

This app does not collect, store, or share any personal information from users. It does not access location, login credentials, device identifiers, or any other form of tracking data.

2. Permissions Requested

The app requests only the following permissions:

  • Notifications: to display alerts when achievements are unlocked.
  • Keep screen on: to ensure a smooth user experience while the app is in use. This functionality is handled natively and does not require explicit user approval.

These permissions are used solely to enhance interaction with the achievement adapter and do not involve any data collection or third-party sharing.

3. Connection to the Adapter

The app connects exclusively to a page hosted locally by the NES achievement adapter via the user's local (Wi-Fi) network. No information is transmitted to external servers.

4. Security

Although the app itself does not handle any user data, we recommend keeping your local network secured with strong passwords and regular updates for a safe experience.

5. Changes to This Policy

If this privacy policy is updated in the future, the revised text will be made available on this same page, and the “last updated” date will be modified accordingly.
